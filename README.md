# Tyr Tecnology - Portfólio Institucional

## 📝 Resumo do Projeto

Este é o site institucional e portfólio digital premium da **Tyr Tecnology**, do especialista Douglas Lima. Desenvolvido com uma estética moderna de *Frosted Glass* (vidro fosco translúcido) e gradientes em malha suaves, o produto tem como objetivo fortalecer a autoridade da marca focada em inovação digital, análise de dados e transparência pública. A interface foi cuidadosamente projetada para engajar visitantes, apresentar soluções tecnológicas de alto impacto e facilitar o contato direto para a geração de novos negócios.

## ✨ Funcionalidades Principais

> 🌟 **Design Glassmorphism Premium**  
> Interface sofisticada com elementos translúcidos (backdrop-blur) sobrepondo *mesh gradients* complexos e responsivos.

> 🚀 **Animações e Micro-interações**  
> Transições de estado fluidas, rolagem suave na página paralaxe espacial e apresentações sequenciais de componentes estruturadas em física interativa.

> 📱 **Experiência Universal (Mobile-First)**  
> Layout 100% responsivo adaptando os grids de serviços, detalhamento de portfólio e navegação perfeitamente da experiência em Desktop para interfaces de toque móveis.

> 🎯 **Módulo de Contato Otimizado**  
> Painel de chamada para ação estratégica integrado diretamente a links de comunicação rápida via WhatsApp (com mensagens pré-definidas) e E-mail corporativo.

> 💼 **Showcase de Portfólio Dinâmico**  
> Vitrine interativa de *cases* de sucesso, destacando prêmios de transparência e excelência de marketing através de *Glass Cards* de mídia dedicada.

## 🛠️ Stack Técnica

| Tecnologia | Descrição / Papel no Projeto |
| :--- | :--- |
| **React 19** | Biblioteca para construção da interface de usuário e gerência de componentes. |
| **TypeScript** | Fornece tipagem estática e maior escalabilidade do código. |
| **Vite** | Bundler ultra-rápido servindo como base da aplicação estrutural. |
| **Tailwind CSS 4** | Framework utilitário configurado para aplicar o modelo e design system do site. |
| **Framer Motion** | Motor avançado usado para coordenar as revelar e orquestrar todas as transições visuais de UI. |
| **Lucide React** | Pacote moderno de iconografia garantindo elegância e padrão minimalista unificado. |

## ⚙️ Instalação e Execução

Para rodar este projeto em seu ambiente local, execute os seguintes passos no terminal:

```bash
# 1. Clone este repositório
git clone URL_DO_REPOSITORIO

# 2. Acesse o diretório do projeto
cd nome-do-diretorio

# 3. Instale as dependências 
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev

# 5. Para compilação otimizada de produção, execute:
npm run build
```
